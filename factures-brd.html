⚙️ Configuration envoi email

Pour envoyer les factures automatiquement, créez un compte gratuit sur EmailJS (200 emails/mois gratuits).

  1. Va sur emailjs.com → crée un compte gratuit
  2. Email Services → Add Service → choisis Gmail → connecte ton compte → note le Service ID
  3. Email Templates → Create Template → copie-colle le template ci-dessous → note le Template ID
  4. Account → General → note ta Public Key

Template à créer sur EmailJS :
To : {{to_email}}
Subject : Facture Pro Forma N° {{invoice_num}} — BRD Services
Body : Bonjour {{client_name}},
Veuillez trouver en pièce jointe votre facture pro forma N° {{invoice_num}} du {{invoice_date}} d'un montant de {{amount_ttc}}.
Cordialement, {{chauffeur}} — BRD Services
Attachment : activer "File upload" avec la variable {{pdf}}
